# Linux Bash 特性

**Linux** 的 **Bash** 有一些特性, 此文件用于讲解

## 命令分隔符

`echo "test1" || echo "test2"` 的意思是 **当 `echo "test1"` 运行失败就运行 `echo "test2"`**, **||** 就是 **当前面的命令执行失败后再执行后面一条命令**

`echo "test1" && echo "test2"` 的意思是 **当 `echo "test1"` 执行完成才运行 `echo "test2"`**, **&&** 就是 **当前面的命令执行成功后再执行后面一条命令**

`echo "test1" ; echo "test2"` 的意思是 **`echo "test1"` 和 `echo "test2"` 一起执行**, **;** 就是 **无论上一条命令的结果怎么样都执行下一条命令**

## 神秘路径学

正斜杠 ( **`/`** ) 在 **Linux** 中代表路径分隔符, **`./`** 可以代表执行某个当前目录下的程序也可以代表 **当前目录**

**`../`** 和 **`./`** 的意思相反, 他的意思是 **上一级目录**

### 演示

`./luci/` = 当前目录下的 luci/ 文件夹

- 图例

```
luci_tmp/ <-当前目录
  luci/
```

`../luci/` = 上一级目录下的 luci/ 文件夹

- 图例

```
luci_tmp/
  luci/
    luci_current/ <-当前目录
```

`./luci-setup` = 运行当前目录下的名为 **`luci-setup`** 文件

## 参数学

``--`` 开头的参数是长参数, 一般代表参数全称

``-`` 开头的参数是短参数, 一般代表参数单字缩写

多个 ``-`` 参数可以合并成一个 ``-`` 后面跟着几个参数, 比如 `-r -f` 可以合并成 `-rf`

一般最常见的 ``--`` 参数就是 `--help` 和 `--version` 了
